🏦 Bank Transaction System

A simple yet powerful Bank Transaction System built to simulate core banking operations like account management, deposits, withdrawals, and fund transfers. This project demonstrates backend logic, data handling, and basic financial transaction workflows.

🚀 Feature
📊 View account balance and transaction history
🧾 Simple and clean transaction flow logic
🔐 Basic validation to prevent invalid transactions

🛠️ Tech Stack
Language:mongodb,react,nodejs,expressjs,jwt,rbac,typescript, JavaScript etc.
Concepts Used:frontend, backend and datbase
Modular Code Design
